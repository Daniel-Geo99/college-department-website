# College Department Website (HTML Assignment 2)

A simple multi-section website for the Department of Computer Science of a sample college,
built with plain HTML5 and a little CSS.

## Files
- `index.html` – the single-page website (header, nav, main sections, footer)
- `style.css` – styling
- `images/logo.svg` – department logo

## Run
Open `index.html` in any web browser. No build step required.

## Concepts demonstrated
Document structure, headings/paragraphs/text formatting, lists, hyperlinks, images,
tables, forms, and semantic elements (`header`, `nav`, `main`, `section`, `article`, `footer`).
